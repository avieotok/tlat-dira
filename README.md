# תלת־דירה

אפליקציה להפיכת שרטוט של דירה או דופלקס להדמיה תלת־ממדית מרוהטת. הכול נמצא בקובץ אחד, `index.html`, ואין צורך בשרת.

## מה אפשר לעשות

**שרטוט והדמיה**
- להעלות שרטוט: תמונה (JPG, PNG, WebP, HEIC) או PDF של תוכנית מכר. Claude מנתח אותו ובונה מודל תלת־ממדי מרוהט.
- דופלקס: שרטוט לכל קומה, עם מעבר בין קומות.
- שבעה סגנונות עיצוב לבית, ריצוף לכל חדר (פרקט, פורצלן, שיש, טרקוטה, בטון ועוד) וצבע קירות.
- סיור בתוך הדירה בגובה העיניים, וייצוא סרטון סיור.

**דיוק ותכנון**
- כיול לפי מידה ידועה מהתוכנית.
- עריכת קירות: הזזת פינות, הוספה, פיצול ומחיקה של קירות, ושינוי אורך ועובי.
- הוספת דלתות, חלונות, ויטרינות ופתחים, עם קשתות פתיחה של דלתות.
- הסרת קירות, עם חישוב גודל החדרים המאוחדים.
- סידור רהיטים: הזזה, סיבוב, שכפול, מידות חופשיות, והוספה מתוך 20 רהיטים.
- בדיקת תכנון: רהיטים שחוסמים דלתות, נכנסים לקירות או עולים זה על זה.
- מדידה במטרים בעזרת קו שנצמד לפינות.
- סימולציית שמש לפי עיר, תאריך, שעה וכיוון הצפון.

**שינויי דיירים והחלטה**
- שכבת חשמל ומים: שקעים, מתגים, תאורה, מזגנים, תקשורת, מים וניקוז.
- הערכת עלות של השינויים, עם מחירון שאפשר לערוך.
- ייצוא PDF לקבלן: מבט תלת־ממדי, גודל החדרים, לפני ואחרי, ורשימת שינויים עם עלויות.
- תצוגת לפני ואחרי עם מחוון.
- השוואה בין דירות עם ציון משוקלל לפי מה שחשוב לך.
- רשימת בדיקה לרוכש.
- שמירה בשם שתבחר, שמירת עותק, וייצוא וייבוא של פרויקטים.

## העלאה ל־GitHub Pages

1. נכנסים ל־github.com ויוצרים מאגר חדש (New repository). קוראים לו למשל `tlat-dira`, ומשאירים אותו Public.
2. בתוך המאגר לוחצים על **Add file ← Upload files**, גוררים את כל הקבצים מהתיקייה (`index.html`, `sw.js`, `manifest.webmanifest`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png`, `README.md`), ולוחצים **Commit changes**.
3. עוברים ל־**Settings ← Pages**. תחת **Source** בוחרים **Deploy from a branch**, ואז את הענף `main` ואת התיקייה `/(root)`. לוחצים **Save**.
4. אחרי דקה או שתיים האתר זמין בכתובת:
   `https://<שם-המשתמש-שלך>.github.io/tlat-dira/`

## התקנה במסך הבית

- **אייפון:** פותחים את האתר ב־Safari, לוחצים על כפתור השיתוף ובוחרים **הוסף למסך הבית**. בפעם הראשונה האפליקציה מציגה הסבר קצר.
- **אנדרואיד:** פותחים את האתר ב־Chrome, פותחים את התפריט ⋮ ובוחרים **התקנת אפליקציה** או **הוספה למסך הבית**.

כשהאפליקציה מותקנת במסך הבית:
- היא נפתחת במסך מלא ומתאימה את עצמה לאזור המצלמה ולפס הבית של האייפון.
- היא עובדת גם בלי אינטרנט, אחרי פתיחה ראשונה עם חיבור. לניתוח שרטוט חדש עדיין צריך חיבור.
- הפרויקטים נשמרים לאורך זמן. ב־Safari רגיל, אייפון עלול למחוק נתונים של אתרים שלא נפתחו כמה שבועות, ולכן מומלץ להתקין, ולגבות מדי פעם בעזרת "ייצוא הפרויקט לקובץ".

## שימוש באייפון

- **הפאנל התחתון:** גוררים את הפס האפור למעלה או למטה, או מקישים עליו כדי לעבור בין חצי מסך למסך מלא. "הסתר" מקטין אותו לשורה אחת.
- **כלים ותצוגה:** הכפתור "☰ כלים ותצוגה" למעלה פותח את כל הכלים. כשהוא פתוח, הפאנל התחתון מתקפל כדי לפנות מקום.
- **תנועה במודל:** אצבע אחת מסובבת, שתי אצבעות מזיזות ומקרבות.
- **שמירת קבצים:** בייצוא PDF, סרטון או פרויקט מופיע כפתור "שמירה או שיתוף". הוא פותח את תפריט השיתוף של האייפון: שמירה ב"קבצים", שליחה בוואטסאפ, במייל ועוד.

## חיבור ל־Claude לניתוח שרטוטים

כדי לנתח שרטוט חדש צריך מפתח API אישי של Anthropic:

1. נכנסים ל־platform.claude.com, ופותחים חשבון אם עוד אין.
2. מוסיפים קרדיט בתפריט Billing.
3. יוצרים מפתח בתפריט **API Keys**.
4. באפליקציה: **כל הפרויקטים ← הגדרות חיבור ל־Claude**, מדביקים את המפתח ולוחצים **שמור**.

**חשוב:**
- המפתח נשמר רק בדפדפן שבו הזנת אותו. הוא לא נשמר בקוד ולא עולה ל־GitHub. אף פעם אל תכתוב אותו בתוך הקבצים במאגר.
- כל מי שנכנס לאתר צריך להזין מפתח משלו. בלי מפתח אפשר לצפות בפרויקטים ולערוך אותם, אבל אי אפשר לנתח שרטוטים חדשים.
- עלות: Opus 5.5 מדויק יותר, ו־Sonnet 5.5 זול ומהיר יותר. ניתוח של שרטוט אחד עולה בדרך כלל בין סנטים ספורים לחצי דולר.

## איפה נשמרים הפרויקטים

הפרויקטים נשמרים בדפדפן (IndexedDB) של המחשב או הטלפון שבו עבדת. כדי להעביר פרויקט למכשיר אחר, או כדי לגבות אותו, משתמשים ב"ייצוא הפרויקט לקובץ" וב"ייבוא פרויקט מקובץ". ניקוי נתוני הגלישה מוחק את הפרויקטים, ולכן כדאי לייצא מדי פעם.

## הערות

- השטחים והמידות הם הערכה לפי השרטוט, ולא תחליף למדידה של מהנדס או שמאי.
- כשהשרטוט לא מזוהה כמו שצריך, אפשר לכתוב בתיבה "שינוי או תיקון בעזרת Claude" מה לתקן.
- קבצי DWG ו־DXF לא נתמכים ישירות. צריך לייצא אותם קודם ל־PDF.
